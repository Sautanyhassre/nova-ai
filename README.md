## Overview
**NOVA AI** is a production-grade, all-in-one artificial intelligence and creative ecosystem built for India's digital future and global scale. The platform unifies 17 specialized studios under a cohesive, high-performance web experience.

## Studios & Architecture
1. **Advanced AI Chat**: Streaming token-by-token reasoning (Fast, Balanced, Deep Reasoning trace), prompt citations, code generation, and export (Markdown/TXT).
2. **Canva-Style Design Studio**: Drag-and-drop vector/SVG canvas, layers, text styling, brand palettes, Indian templates (Diwali banners, unicorn decks, hiring posts), and PNG/SVG export.
3. **Image Studio**: High-resolution text-to-image synthesis, style presets (Photorealistic, Cyberpunk, 3D Render, Anime, Watercolor), and aspect ratios (`16:9`, `1:1`, `9:16`, `4:3`).
4. **Video Studio**: Script-to-video storyboard sequencer, scene duration controls, multi-track timeline, and rendering queue.
5. **Autonomous AI Work & Agents**: Multi-step task decomposition, execution logs, tool permissions, and reviewable deliverables.
6. **Productivity Suite**:
   - **Documents**: Rich-text drafting, summarization, and export.
   - **Presentations**: Slide deck outline generator, themes, presenter notes, and slideshow mode.
   - **Spreadsheet Studio**: Interactive cell grid, formula evaluation (`=SUM`, `=AVERAGE`), and dynamic chart visualization (July-Sept Revenue).
7. **Code Studio**: Multi-file editor with live sandboxed preview and AI explanation/refactoring.
8. **Voice & Speech Studio**: Indian English & Hindi text-to-speech synthesis with interactive audio waveform visualization.
9. **Projects & Cloud Storage**: Folder hierarchy, search, file explorer, and storage quota meter (42 GB / 100 GB).
10. **India Billing & Subscriptions**: 3 tiers (PLUS ₹499/mo, PRO ₹1,999/mo, ULTRA ₹10,699/mo) with 18% GST breakdown, GSTIN input, and UPI/Razorpay checkout simulation.
11. **Admin Console**: Multi-model provider routing, GPU job queue telemetry, and revenue monitoring.

## Getting Started
```bash
# Navigate to project
cd c:\Users\Balaji.g\nova-ai

# Install dependencies
npm install

# Build for production
npm run build

# Start live production server
npm run start -p 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
